# Financials Simple Project

Este repositório foi desenvolvido com base na planilha **Financials Simple**, onde os schemas foram segmentados e as dependências comuns entre as tabelas foram detectadas para proporcionar um maior entendimento do negócio.

##  Objetivo
O projeto tem como finalidade organizar e estruturar os dados financeiros de forma clara e acessível, permitindo:
- Melhor compreensão das relações entre tabelas.
- Identificação de dependências comuns.
- Suporte a análises de negócio mais consistentes.

##  Estrutura do Repositório
- **Schemas Segmentados**: Cada tabela foi organizada em seu próprio schema para facilitar a navegação e manutenção.
- **Dependências Detectadas**: As relações entre tabelas foram mapeadas para evidenciar como os dados se conectam.
- **Documentação**: Inclui explicações sobre cada tabela e suas principais colunas.

## Benefícios
- Clareza na visualização dos dados.
- Facilidade para analistas e desenvolvedores entenderem o modelo de negócio.
- Base sólida para relatórios e dashboards.

## Tecnologias Utilizadas
- Planilha **Financials Simple** como fonte de dados.
- Ferramentas de modelagem e organização de schemas.
